Prompts Used

I used ChatGPT to help create the starting point for my Baseball Hub website for the CPS110 midterm assignment.

My prompts asked for:

A five-page baseball information website with a home page, pitching page, equipment page, game page, and about page.

Shared navigation links connecting all five HTML pages.

An external CSS stylesheet with a consistent baseball-themed design.

Four original SVG illustrations for baseball, pitching, equipment, and a baseball field.

Beginner-friendly HTML and CSS that I could save and test in VS Code.

I reviewed and saved the generated files as the starting point before completing the required folder restructuring and path changes by hand.
