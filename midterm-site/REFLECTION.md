Midterm Site Reflection

For this project, I created a baseball website called The Baseball Hub. The original website had five HTML pages, a shared navigation menu, CSS styling, and local images. I then reorganized the website by moving the pitching, equipment, and game pages into separate folders. I also moved all the local images into an images folder and the stylesheet into a css folder.

The most challenging part was fixing the file paths after moving everything. Relative paths depend on where the HTML file is located, while root-relative paths start from the website's root. Because my website is hosted inside the midterm-site folder, my root-relative paths include /midterm-site/.

I tested the navigation and images in my browser to make sure the pages worked after the changes. I also added an external baseball field image with a visible credit link.

This project helped me understand how websites organize files and how important correct file paths are. I learned that moving files can break links and images if their paths are not updated. Testing the website after restructuring helped me catch and fix those problems.
